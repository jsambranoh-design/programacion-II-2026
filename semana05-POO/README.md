Nombre del proyecto==
Sistema de gestion de envios
Descripción breve==
Este programa se enfoca en dar dos tipos de coverturas, nacionales e internacionales con el cual se muestra un desglose de que precios son los que se toman por cada cobertura
y ademas pide todos los datos necesarios para identificar un paquete y realizar los cálculos de peso y distancia.
Objetivo.==
Tener un mejor entendimiento sobre la programación orientada a objetos, de todos los pilares del mismo y cómo se trabaja en cada clase.
Temas aplicados. ==
programación orientada a objetos, polimorfismo, sobrescritura, herencia, constructores, validación de datos, encapsulamiento y formas de acceder a datos encapsulados.
