Nombre del proyecto.
Cálculo de áreas con POO \
Breve descripción.
El programa funciona de manera que las variables ya estan definidas dentro del sistema sin necesidad de que el usuario ingrese datos, estos datos son asigados a los 3 diferentes tipos de objetos creados por cada figura los cuales son referencias de las 3 clases creadas paara cada figura  y la una clase figura la cual se uso como plantilla para funcionamiento de las clases de las figuras.\
Figuras implementadas. Circulo. Triangulo y Rectangulo\ 
Instrucciones para ejecutar el programa. El programa ya tiene las variables definias por las cuales no necesitan de inteaccion externa, solo correr el programa en la terminal de intelli J
